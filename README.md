# Neko Chat (Android)

Chat app for your `model.cde` (MiniGPT from llm.py). Pure Kotlin inference, no PyTorch, tiny APK.

1. Push this folder to GitHub (branch `main`).
2. Open the **Actions** tab, wait for "Build Android APK", download the **NekoChat-release** artifact.
3. Install the APK, tap **Import model**, pick your `model.cde`, then chat.
